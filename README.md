# food_delivery

Application de livraison de nourritures

Fonctionnalités majeures : 
1. Page d’accueil (affiche les produits populaires et les produits recommandés)

2. Connexion et inscription (inscription avec numéro de mobile et code de vérification)

3. Panier d’achat (un vrai panier d’achat avec ajout et suppression d’articles en temps réel)

4. Page d’historique du panier local (utilisation du stockage local)

5. Page d’historique du panier sur le serveur (synchronisation avec la base de données)

6. Page de profil (informations personnelles)

7. Page des plats populaires (voir les plats populaires, ajouter ou retirer des articles du panier)

8. Page des plats recommandés (voir les plats recommandés, ajouter ou retirer des articles du panier)

9. Fonction “Commander plus” (nouvelle fonctionnalité ajoutée qui aide à passer commande)

10. Aller à la page de connexion (authentification obligatoire avant de passer une commande)

11. Page d’adresse (gestion des adresses avec authentification avant de passer une commande)

12. Page Google Maps (pour sélectionner un lieu et enregistrer une adresse)

13. Recherche d’adresse (recherche d’adresse ou de lieu via Google Maps et enregistrement dans la base de données)

14. Backend (back-end pour afficher les informations utilisateur et les détails des commandes)

15. Création de nouveaux articles (dans le back-end, possibilité de créer de nouveaux plats)

16. Paiement PayPal (paiement via PayPal synchronisé avec la base de données)
